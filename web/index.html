⚠️ Danger zone — clear all data

This permanently deletes every operational record in the current environment. It cannot be undone, there is no backup, and there is no way to get the data back.

Deleted for good:

  • Trips — every dispatch record, every day, all history
  • Waybills — suggested and confirmed alike
  • Outlets — the destination list built up from imports
  • Route Frequency Log — the delivery-frequency history
  • Audit Log — the record of who changed what

Kept:

  • Employees, Trucks, Users, Billing Categories, Route Type Map, Default Assignments
  • Waybill Prefixes — including their sequence counters, so numbering carries on where it left off
